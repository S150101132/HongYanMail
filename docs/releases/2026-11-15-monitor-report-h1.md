# H1 服务器巡检邮件看板（2026-11-15）

## 做了什么

每天的 `[OT-MON] CHECK <级别> <时间>` 巡检邮件（纯文本：`CHANGED ITEMS`、`CURRENT STATUS`，每行「检查项 级别 说明」）在阅读栏里换成状态视图：

- 顶部一块总结：「N 项需要看」或「全部正常」，颜色随整封的级别（标题里的级别优先），下面是各级别的个数。
- 「和上一封相比有变化」：邮件里 `CHANGED ITEMS` 的行。
- 「需要看」：不是 OK 的项，严重 → 警告 → 未知排序，常见说明（没找到结果行、连不上、端口没监听）补一句中文。
- 「全部检查项」：按 数据库集群 / 备份 / 数据库代理 / 站点与服务 / 磁盘 / 定时任务 / 巡检程序 / 其他 分组，全正常的组收起，有问题的组展开；检查项和定时任务换成中文名；百分比画小条，80% 起黄、90% 起红（只是条的颜色，级别以邮件为准）。
- 「看原文」展开原文；公司免责声明不显示。

只认主题含 `[OT-MON]` 且正文有 `CURRENT STATUS` 的纯文本邮件，认不出就照常显示原文。全在页面里做（`web/monitor.js`），后端不变，不调用 AI。

顺带修了：深色主题下阅读栏的 iframe 没声明 `color-scheme`，Chromium 在深色父页面里给它铺了白底（巡检视图浅色字看不清）；现在按主题声明，HTML 邮件的白纸底不变。

## 验证

- `tests/test_monitor_report.py`（node）：解析、问题排前、全正常、认不出的返回 null、转义、阅读栏接线；用 `demo.py` 的合成巡检邮件（`MONITOR_ID = 'demo40'`）。
- 用户给的 11-15 那封真实样例只在本机解析、只看个数：级别 UNKNOWN、变化 1、检查项 27、问题 1，和原文一致；没有存内容。
- 演示截图浅色 / 深色走查（`tools/screenshot_app.py` 加了 `monitor-report` 一步）。
