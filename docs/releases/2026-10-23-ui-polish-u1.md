# U1 界面打磨（2026-10-23）

一轮，有终点：按开发顺序表 U1 的检查单过一遍收件箱、阅读、写信、今天、任务五页，外加菜单、提示条、设置。只改 `coremail_desktop/app/web/style.css`，不加功能、不加概念。

## 改了什么

| 检查项 | 改前 | 改后 |
| --- | --- | --- |
| 字体 | 19 种字号（11–22px，含 11.5 / 12.5 / 13.5 / 14.5 等） | 5 级变量 `--fs-xs/sm/md/lg/xl` = 12 / 13 / 14 / 16 / 20；中文最小 12px。只剩文件类型角标 8px、登录与启动页 24 / 28px |
| 层级 | 已读邮件的头像和未读一样醒目；头像 15px 字 | 已读行头像退一步（不透明度 .82），头像字 14px；「写邮件」加粗，作为左栏唯一主操作 |
| 颜色 | 约 40 处写死的状态色，深色下红色（逾期、受阻）偏暗，提示条和深色背景混在一起 | 成功 / 提醒 / 危险及其底色、边框收进变量，深色各有一套（危险色 `#f97066`）；提示条有自己的底色和描边 |
| 动效 | 悬停是硬切换；不理会系统「减少动画」 | 按钮、文件夹、邮件行等 120ms 过渡；按下下沉 1px；系统开了减少动画时全部关掉 |
| 微交互 | 键盘焦点除输入框外几乎看不见 | 按钮、行等 `:focus-visible` 显示 2px 强调色外框（输入框保留原来的聚焦样式，鼠标点击不出框） |
| 数字 | 只有个别地方等宽 | 文件夹计数、列表日期、会话封数、今天页日期行用等宽数字 |
| 窄窗口 | 1024 宽下三栏正常 | 照旧正常（截图核对） |
