# 2026-10-24 · G2 每日速览：36氪 9点1氪 + GitHub Trending，单独一页

用户要加 36氪「八点一氪」每日新闻（https://36kr.com/user/5652071），并觉得 Trending 放在三栏里不美观。

## 改了什么

- 左栏「Trending」改名「每日速览」，打开后占满列表和阅读栏的位置（`#daily-view`，`.app.daily-mode`），内容居中、最宽 1240px。两栏各自上下滚动，栏目标题固定在顶部，刷新后各自停在原位置；窗口窄于 1100px 时两栏上下排，整页一起滚动。
- 左栏是 36氪「9点1氪」当天简报：日期、「阅读原文」（只开 36kr.com）、今日热点导览、按栏目（TOP3大新闻、AI最前沿……）列出新闻标题和摘要，摘要默认两行，点开看全文。
- 右栏是 GitHub Trending 卡片：排名、项目名、今日新增星标、中文简介、语言 / 星标 / Fork、英文原描述；点卡片在浏览器打开（原来阅读栏里的项目卡片去掉）。
- 简报先出，Trending 后出（两者共用 AI 线程，简介约半分钟）。页面右上「刷新」两边都重新抓。
- 在等别人、待我确认、本周概括子页仍是三栏，顶部「← 每日速览」。

## 数据来源

- 36kr.com/user/5652071 和 36kr.com/feed 返回的是人机验证页（JS 挑战），不去绕过。
- www.36kr.com/feed（公开 RSS）可直接读，包含当天「9点1氪」的全文（这个栏目已从 8点1氪 改名，两个名字都认）。正文结构：`<h2>今日热点导览</h2><ul>…</ul>`，之后每个 `<h2>` 是栏目，全加粗的 `<p>` 是新闻标题，其后的 `<p>` 是正文；图片丢掉，只留纯文本。
- 缓存 `HongyanData/news/latest.json`：拿到当天那期就不再联网；当天还没发布时，最多每 30 分钟再看一次；断网时显示上一期并提示。

代码：`coremail_desktop/app/news.py`、`backend.daily_news`、`web/today.js`（`showDaily`、`tdDaily`）、`style.css`（`.dv-*`）。
