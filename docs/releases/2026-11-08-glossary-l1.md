# L1 术语统一（2026-11-08）

用 `/grill-with-docs` 理清邮件状态的叫法，定在根目录 [GLOSSARY.md](../../GLOSSARY.md)；代码、界面文字、AI 提示和工具说明里的旧叫法按它改过来。只改文字，不改功能。

- **界面上看得到的**：「在等别人」邮件列表的标题（原「等回复」）、「不用跟进」的提示和撤销提示、理解设置和开启说明里的三类名称（「要我知道」→「知会」）、本月统计里的「在等别人 N 封」。
- **AI 看得到的**：问鸿雁的说明和 `pending_mail` 工具说明不再提「待我处理」；`followups` 工具说明以「在等别人」开头，侧栏步骤显示「在等别人：N 封」；理解新邮件的提示里 know 写作「知会」，原来列在 know 下的「知会」改为「通知」；起草材料里的分类规则名同样用「知会」。
- **注释和测试说明**：同步改掉。
- **没改的**：「本周你需要知道的」（本周概括的标题，说的是每周汇总，不是「知会」邮件）；「需要我做什么」「哪些需要我做」这类普通句子；命令框里「在等别人」的搜索别名仍收「等回复」「催办」，敲旧词照样能找到；「催办」作为提醒对方的动作照旧使用。
