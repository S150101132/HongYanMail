# R4 做减法：写邮件下拉菜单、导出 .eml、新窗口按钮、甘特图、要我做 / 知会筛选、标签；改为双击 .eml、Ctrl+C 复制邮件（2026-10-22）

## 改了什么

- 「写邮件」按钮旁的下拉箭头去掉，按钮恢复为一整块；菜单里的「从模板新建…」「打开 .eml 邮件文件…」一起去掉。
- 命令框（Ctrl+K）的「从模板新建」「导出为 .eml」去掉。模板本身保留：写信窗口点「模板」套用或存为模板，设置里管理模板；相关提示文字改为指向「模板」按钮。
- 阅读栏「⋯」去掉「导出为 .eml…」和「在新窗口中打开」，完整工具栏上的「在新窗口中打开」按钮也去掉；双击邮件、Enter 照旧弹出新窗口。
- **Ctrl+C 复制邮件**：在列表或阅读窗格里（没有选中文字时）按 Ctrl+C，当前邮件——多选时是选中的全部——以 .eml 文件放进剪贴板，可粘贴到资源管理器文件夹、聊天窗口或其他邮件里当附件；选中了文字时 Ctrl+C 照旧复制文字。弹出的阅读窗口里也可以。加密邮件复制的是加密原件（对方需要证书才能打开），不会悄悄变成明文。文件先写到系统临时文件夹下的 `Hongyan-copy`（本机不允许时写到数据目录下的「复制的邮件」），下次复制时清掉上次的。
- **双击 .eml 用鸿雁打开**：
  - `Hongyan.exe <文件.eml>`：鸿雁没在运行时启动并在只读阅读窗口打开它（等主页面加载完）；已在运行时，第二次启动把路径交给正在运行的鸿雁打开后退出。
  - 单实例套接字原来只认 `activate`，现在还认 `open\t<路径>\n`（最长 4096 字节）；只打开确实存在的 `.eml` 文件，其他一律忽略。套接字仍只限本 Windows 账户。
  - 文件读不到、不是邮件、超过 40 MiB 时弹出固定提示（新增错误码 `EML_UNREADABLE`）。
  - 安装程序新增任务「双击 .eml 邮件文件时用鸿雁打开」（默认勾选）：在 HKCU 登记 `Hongyan.eml` 文件类型、`.eml` 默认值和「打开方式」列表；注册表写不进时不报错、不中断安装；卸载时删掉登记。之前选过别的邮件程序时，Windows 可能会问一次用哪个程序打开。
- 邮件里的 .eml 附件照旧在应用内打开。
- **去掉甘特图**（P1 的一部分）：任务列表上方的「甘特图」按钮、`tasks_gantt` / `plan.gantt` 和相关样式去掉；任务关系（上级 / 子任务、前置 / 后续，写在「阻塞与依赖」里）、父任务汇总进度、前置完成后的解除受阻提示都保留。
- **「要我做」「知会」改为小标识**：收件箱列表头的「要我做」「知会」筛选（以及命令框的「只看要我做 / 知会」、筛选里的「全部标为已处理 / 已读」）去掉；AI 读过的邮件在列表最后一行、要点前面带一个小标识——「要我做」（蓝）或「知会」（灰），截止日期和「已回复」照旧在主题前。AI 不确定、可以忽略、已处理的不带标识；右键菜单照旧可以纠正分类或标为已处理。「今天」页和「在等别人」不变。
- **去掉标签**：左侧栏的「标签」、邮件行和阅读窗格上的标签、阅读栏 / 多选栏的标签按钮、L 键、右键「标签…」、设置里的「标签」页都去掉，只留星标。服务器上的标签和网页版不受影响；网页版建的「添加标签」收信规则在设置里照旧显示，编辑时保留这个动作，但新规则不再提供它。
