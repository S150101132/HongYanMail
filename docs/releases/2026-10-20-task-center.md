# 2026-10-20 · v0.9 任务中心 + Excel 无损迁移

依据：[任务中心设计](../superpowers/specs/2026-10-20-task-center-design.md)。目标：Saudi-NG 的两份任务工作簿改由鸿雁维护，告别手改 Excel 和 ChatGPT Work。不含 AI（v1.0 再做）。

## 功能

- 左侧「本机」下的「任务」：显示未完成数。列表可切换 未完成 / 已完成 / 已取消 / 全部，可全文搜索；计划日期已过的未完成任务标红（没有计划日期的永远不算逾期）。
- 详情：15 个字段（空着的负责人边界和验收标准显示「待确认」），以及「时间线」（每次改动的字段旧值 → 新值和依据）、「进展与历史记录」原文、「关联邮件」。
- 操作：新建、记录进展、编辑、标记完成、取消任务、重新打开。每次保存前先显示「检查修改」差异；保存后重新读取任务库核验，并列出全部未完成任务和总数。在正式模式下，同时给出可复制的 git 提交说明。
- 阅读邮件时，「更多 → 关联到任务…」可把邮件挂到一条未完成任务上（手动操作，v1.0 的 AI 关联也用这张表）。
- 设置 → 任务中心：选择任务文件夹 →「检查并导入…」（显示导入报告和往返校验结果，导入为演练）→「切换为正式…」。另有「立即导出」「对照 Excel」（演练时比较两边）「从 任务数据.json 恢复…」「停用正式模式…」（回滚）。

## 规则（来自任务目录的 AGENTS.md 和任务管理说明）

- 状态只能是 7 个之一。已完成 / 已取消只能通过各自的操作进入；归档后的任务只能「重新打开」。
- 新编号 = 全部任务（包括已归档）的最大编号 + 1；编号不能修改。
- 完成日期没填时，默认沙特当天（固定 UTC+3）；填了就用所填日期。取消必须写原因；取消日期只有填了才写入结束日期。
- 改成「受阻」时必须填写阻塞与依赖。新任务默认「未开始」，负责人默认「用户本人」；其他字段一概不补。
- 「进展与历史记录」只追加 `YYYY-MM-DD：…` 行。改动原有文字算更正，必须写依据，旧全文保存在时间线里。
- 导入、导出不改动「最近更新日期」。

## 数据与导出

- 任务库：`HongyanData\tasks\tasks.db` + `tasks.key`。与邮件缓存分开存放，不随账号变化，不登录也能用。每行都是 AES-GCM 密文，密钥受 DPAPI 保护。每次改动放在一个事务里，提交前读回比对；保存后用新连接重新读取并核验。
- 备份：每天一份（保留 14 份），导入、恢复前各备份一份，放在 `tasks\backup\`。这些备份只能在这台电脑、这个 Windows 用户下打开；可以带走的备份是任务文件夹里的 `任务数据.json`。
- 导出：演练时写到 `tasks\export-trial\`，任务文件夹只读。正式模式下每次改动后写 `未完成任务.xlsx`、`已完成任务.xlsx`、`任务数据.json` 到任务文件夹：
  - 先导出、读回、逐格比对，两份工作簿一起替换；
  - 同样的数据生成的字节完全相同；
  - 只用标准库读写，不引入 openpyxl。
- 外部修改保护：
  - 文件和鸿雁上次写出的不一样 → 暂停导出，不覆盖。可以「读入外部修改」：只读入鸿雁之外改过的格子，作为待审核事件逐条采纳 / 驳回；也可以「以鸿雁为准」：先把外部文件复制到 `tasks\displaced\`，再覆盖。
  - Excel 正在打开文件（`~$` 锁文件）→ 改动已保存，标为「待导出」，可以重试。
- 第 2 行的说明改为「由鸿雁任务中心导出：请在鸿雁中修改，不要直接编辑本文件。」
- 新增错误码：`TASK_NOT_FOUND`、`TASK_INVALID`、`TASK_STATUS_INVALID`、`TASK_BLOCKER_REQUIRED`、`TASK_REASON_REQUIRED`、`TASK_CONFLICT`、`TASK_VERIFY_FAILED`、`TASK_NOT_IMPORTED`、`TASK_FOLDER_INVALID`、`TASK_FOLDER_LIVE`、`TASK_IMPORT_LAYOUT`、`TASK_IMPORT_DUPLICATE`、`TASK_IMPORT_INVALID`、`TASK_ROUNDTRIP_FAILED`、`TASK_EXPORT_LOCKED`、`TASK_EXPORT_FAILED`、`TASK_STORE_LOCKED`。

## 待真机验收（用户从资源管理器启动鸿雁）

1. 先在任务文件夹中 `git commit` 当前状态。
2. 设置 → 任务中心 → 选择 `D:\work\00_all_project\32. Saudi-NG\0-0-NG-TASK` →「检查并导入…」，核对报告中的数量。
3. 演练中随意试用；确认后点「切换为正式…」，用 Excel 打开导出的两份文件，检查下拉、着色、冻结、表格和行高。
4. 在任务文件夹中 git 提交「切换到鸿雁任务中心」，并把 AGENTS.md / 任务管理说明.md 改为「工作簿由鸿雁导出」；`变更记录.md` 末尾追加一条切换记录后冻结。

## 补充：自然语言操作任务（2026-10-20，提前自 v1.0）

- 任务列表顶部有输入框，用一句话说要做什么，例如「302 客户回复周四开通端口；333 今天完成了」。AI 按任务规则生成操作计划，可以记录进展、修改、标记完成、取消、重新打开、新建。每一项都先由手动操作同一套校验做一次预演（不写入），显示改动对比；不符合规则的项标为「不会执行」并写明原因。点「确认执行」后逐项执行、导出、核验。
- AI 不确定是哪条任务、或缺少关键信息时会提问，并且不执行任何操作；你在同一个输入框里回答，会接着这次对话继续。
- 时间线把这类改动标为「AI」，并记录原话（「指令：…」）。
- 隐私：第一次使用时会提示，这句话、未完成任务和这句话提到的任务的内容会发送到「设置 → AI 助手」中配置的服务；不会发送全部归档，只发送最近 30 条归档任务的编号和简述。
- 代码：`tasks/assistant.py`（提示词、上下文、计划解析）；`center.py` 的 `preview` / `run_plan`；后端 `tasks_command`（AI 线程）和 `tasks_command_run`（任务线程）。演示模式由本机生成计划，不联网。
- 测试：新增 4 项，覆盖计划解析、只预演不写入、执行与记录、提问与错误输入、演示模式。

## 补充：邮件 → 任务、时间线、撤销（2026-10-20）

- 邮件右键（单封或多选，最多 5 封）和阅读窗格「更多」里新增「转为任务（AI）…」：AI 读邮件后判断是新建还是更新哪条任务。对话框里可以一键改为「新建任务」「更新 #编号」（AI 推荐的候选，或手填编号）。AI 提问时，在对话框里补充信息后重新生成。保留手动「关联到任务…」。
- 邮件正文用随机标记包住，作为资料交给 AI，邮件里的文字不能当指令；附件只给文件名。加密邮件每次都要你同意。
- 用邮件更新时，进展日期默认是邮件日期（沙特时间），可以改。历史行末尾带 `（邮件：主题，MM-DD）`，Excel 里也能看到。事件记录依据的邮件，并自动关联邮件。
- 时间线：改动和关联邮件按时间混排；由邮件产生的改动显示依据邮件，点击打开。
- 双向：已关联的邮件在列表和阅读窗格显示「#编号」，点击跳到任务。
- 有新邮件：已关联邮件所在会话（同一主题，至少 6 个字）出现更晚、还没关联的邮件时，任务列表标「有新邮件 N」，「关联邮件」页可以一键「用这封更新」。只提示，不自动修改。
- 撤销：时间线上最近一次改动旁边有「撤销这次修改」；字段已经被再次改动、或者是新建的任务，不能撤销。撤销本身也记入时间线。撤销不会取消由该改动产生的邮件关联。
- 测试：新增 3 项（邮件更新的日期、来源和关联；新回复提示；撤销规则和数量上限），全套 605 项通过。

## 补充：搜索并入 AI 输入框、事件演进图（2026-10-20）

- 任务列表只保留一个 AI 输入框。查找类的话（「哪些任务受阻？」）由 AI 转成列表筛选，答案显示在框下面，可以点「显示全部」恢复；只输入编号就在本机直接打开；没有设置 AI 时按关键词在本机查找。
- 事件演进图（`tasks/story.py`）是每条任务的默认视图，按时间倒序，最新的在最上面并显示当前状态。环节来自「进展与历史记录」的每一行（导入的任务也有完整过程），再加上没有写入历史的编辑、撤销和单独关联的邮件。AI 为每个环节生成短标题、一句说明和类型（决定图标），结果加密缓存，每个环节只生成一次；没有 AI 时用原文的第一句。点击环节可以看原文、依据的指令或邮件、字段改动，最近一次改动可以撤销。原来的时间线改名为「变更记录」。

## 补充：标题更有概括性、新邮件自动更新（2026-10-20）

- 演进图标题：提示词改为写「进度节点和结果」（4～10 个字，例如「申请开通网络」「网络未通，待客户」），不以「用户确认」等开头；按旧提示词生成的标题会重新生成（`TITLE_VERSION`）。没有 AI 标题时，原文开头的「用户确认 / 本轮 / 补充」等字样会去掉。设置好 AI 后，第一次打开任务会自动询问一次授权；同意后打开任务就自动生成标题，并在后台为全部未完成任务生成。
- 新邮件自动更新（用户选择：自动记进展，状态改动等确认）：启动约 20 秒后和之后每 3 分钟检查一次。未完成任务的关联会话里出现新邮件时，鸿雁先下载正文（不标为已读），再交给 AI 阅读：
  - 只是新进展、不改状态的，直接记入任务（标「AI」，依据写「自动更新：新邮件…」，可以撤销）；
  - 要改状态、完成或取消的，生成「待确认」建议，显示在演进图最上方和任务列表上（「待确认 N」），一键采纳或驳回；
  - 加密邮件、AI 有疑问、或判断不出的，只保留「有新邮件」提示。
  每封邮件只处理一次。前提是已经同意在任务中心使用 AI，并且设置好了 AI。

## 补充：周报（2026-10-20）

- 在任务输入框说「生成周报」或「上周周报」，会直接生成；其他说法（例如「10 月 1 日到今天的周报」）由 AI 识别时间段，最长 62 天。每周从周日开始，日期按沙特时间。
- 鸿雁先汇总这段时间带日期的进展行、新建 / 完成 / 取消 / 重新打开记录，以及全部未完成任务的状态、下一步和阻塞（`tasks/report.py`），再由 AI 写成中文内部周报，分四节：本周完成、本周进展、受阻与风险、下周计划；只依据这些材料，不编造。HTML 由鸿雁生成，AI 写的文字一律转义；末尾附「未完成任务一览」表格。
- 生成后打开写信窗口：主题和正文已经填好，签名保留在下方；收件人由用户填写，不会自动发送。
