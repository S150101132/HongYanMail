日期：2026-10-16。用户已确认按“界面与交互修复 → 基础功能补齐 → 实际验证”的顺序继续。当前仍是预览版，本记录不代表完整目标已完成。

## 已实施

- 调整登录卡片、工具栏、文件夹、阅读区与浅色/深色主题；工具栏收起低频工具，避免窄窗口拥挤。
- 邮件列表按发件人、日期、主题和已读/附件状态分别排版，长文本截断；仍使用虚拟列表模型。
- 加入明确限于已加载邮件的“仅未读”筛选；键盘改变文件夹选择会实际加载邮件；登录默认选择已识别的收件箱。
- 列表与正文分别判断结果是否过期，选择邮件不再丢弃当前文件夹的有效刷新；分页和刷新请求去重并显示忙碌状态。
- 切换邮件、文件夹、锁定证书和会话失效均清理旧的主题、头部、附件入口及正文。
- 正文查找接入实际 WebEngine 或文本回退控件，不再误用 QWidget.find。
- UI 请求上下文只保留结果路由所需字段，不保存登录密码或完整 MIME；草稿保存/发送回执归属于发起操作的编辑器。
- 按主题和最近修改时间恢复加密草稿，不建立明文主题索引；恢复另一份草稿不会替换正在使用的编辑器。
- 从解析后的 MIME 提供附件另存为，使用 QSaveFile 原子提交；包含 `.eml` 附件时保留原始解码字节，不重新序列化。
- 正文使用 16px 字号、行距、自动换行和主题背景。应用样式由随机 nonce 授权，邮件自带样式仍被移除，脚本及远程资源仍被阻止。
- HTML 渲染成功之前立即展示纯文本；渲染失败或进程终止时保留可读文本，不再留下空白。HTML 就绪回调需匹配本次文档随机标记，旧页面不能重新显露。
