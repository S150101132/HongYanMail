# 2026-10-22 · 回复即已处理（R1a）、阅读条合并（R1b）、「今天」页（R2a）、统一一个 AI 入口（R2b）

依据：[「今天」页与统一一个 AI 入口设计](../superpowers/specs/2026-10-22-today-and-one-assistant-design.md)。用户 2026-10-22 从产品角度复盘「流程用起来不顺」，定下原则「最好的工作方式就是最简单的」，要求先做完这次优化，再在新版本上试用一周（R0）。

## 功能

### R1a 回复即已处理

- 回复、全部回复或转发一封「要我做」的邮件，发出后（含进发件箱、定时发送），这封和同一会话里更早的「要我做」一起标为已处理，提示「已回复：N 封『要我做』标为已处理 · 撤销」，撤销只恢复这一次改过的。
- 只看 AI 确定的「要我做」；没开理解层时什么都不做。从任务助理起草的回复照旧提议「记一条进展」。
- 后端 `understand_answered(mid)`；页面在 `sendOutcome` 之后调用（`understand.js`）。

### R1b 阅读条合并

- 邮件上方只剩一条 AI 提示：要你做什么 / 截止 / 项目 + 动作。
- 任务候选从单独一行变成这条上的按钮「关联 #N」（悬停看理由）。
- 「这个项目最近」默认收起：点提示条上的项目名展开或收起，记住选择（下一封邮件照旧）。
- AI 回复面板本来就是点「AI 回复」才出现，没有改。

### R2a 「今天」页

- 左栏最上面「今天」，带件数；默认登录后打开（设置 → 通用 → 启动时打开：今天 / 收件箱）。
- **只有一张清单**：AI 确定的「要我做」邮件 + 未完成任务中已逾期、今天或 3 天内到期的（受阻的放在「在等别人」），按 已逾期 → 今天到期 → 接下来 → 没有截止日期 排。
- 清单上方一行：日期、逾期 / 今天件数，以及只在有内容时出现的链接：**在等别人 N**（等对方回复的邮件 + 受阻任务）、**待我确认 N**（任务中心待确认的 AI 建议和 Excel 外部修改：AI 建议可直接采纳 / 驳回，两条以上可全部采纳 / 驳回；Excel 修改去任务中心看差异）、**本周概括**（原来在收件箱「知会」上方）。每个子页左上「← 今天」返回。
- 用现有三栏：点邮件在右边阅读，回复、已处理都在原地；点任务在右边显示任务卡（状态、计划完成、最新进展、下一步、阻塞、负责人，按钮 记录进展 / 标记完成 / 在任务中心打开），保存后清单马上更新。
- 没开理解层或没导入任务时，顶部各一行提示和「去设置」。
- 后端 `today_overview()`、`today_waiting()`，只读缓存和任务库，不调用 AI、不联网（在任务线程上运行）。
- **撤掉**：收件箱「知会」上方的本周概括、已发送列表头的「等回复」筛选（命令框「在等别人」「待我确认」「本周概括」直接到今天页）。

### R2b 统一一个 AI 入口

- 对话只在右侧侧栏，标题改为「问鸿雁」（Ctrl+J）；空白时的示例问题随页面变化（任务页、今天页、邮件）。侧栏带上当前邮件、任务中心选中的任务，以及今天页打开的任务卡。
- **撤掉任务页的 AI 输入框和对话区（T1）**，换成一个不用 AI 的筛选框（关键词即时筛选，输入编号回车直接打开）和一个 ✦ 按钮（打开侧栏）。周报从输入框移到标题栏「周报」按钮（本周 / 上周），命令框也有「写本周周报」「写上周周报」；命令框输入编号出现「打开任务 #N」。
- 撤掉之前先把 T1 / T1b 的能力补进侧栏：
  - `plan_tasks` 支持新建任务的占位编号 `ref: N1`，其他操作写 `#N1`，执行时换成真实编号；
  - 规则：新增前提 / 支线任务 = 新建 + 原任务记进展并写「依赖 #N1」；记进展前对照 latest 和最近进展，不重复记；
  - 计划卡片两项以上时逐项勾选，执行只跑勾选的（`assistant_plan_run(plan, picks)`）；对话记下「没有勾选 N 项」，AI 不再重复提出。
- 搜索框旁的 ✦ 保留，作为同一个侧栏的按钮（搜索框里有字时作为问题发出）；它不是另一个入口。
- 后端 `tasks_command` / `tasks_command_run` 暂时保留（页面不再调用），等试用后确认没有遗漏再删。

## 验证

- 测试：`tests/test_today.py`（清单排序与 3 天边界、受阻进「在等别人」、已处理后移出、没开理解层 / 没导入任务、不调用 AI、回复标记会话、撤销、不确定的不动；页面接线）；`tests/test_assistant.py`（侧栏建前提任务写依赖、逐项勾选与非法 picks、对话记下未勾选）。全量 747 项通过（11 项跳过）。
- 演示走查：`HONGYAN_WALK_R2=1 python tools/screenshot_app.py analysis/screens-r2 light 1440`，截图在 `analysis/screens-r2/`：今天页、今天页读邮件、回复后提示、任务卡、在等别人、本周概括、待我确认（空）、合并后的阅读条（收起 / 展开）、任务页筛选框、任务页侧栏。

## 待真机验收（R0 一起做）

在新版本上试用一周时顺带确认：

1. 打开鸿雁先到今天页；清单里的邮件和任务是不是「现在该我做的」，3 天的范围合不合适。
2. 回复一封「要我做」后它从清单消失；误判时点「撤销」。
3. 今天页点任务记进展、标完成，清单是否马上更新。
4. 侧栏说「给 #N 加一个前提任务：…」，卡片上逐项勾选后执行，看依赖是否写上新编号。
5. 卡住的地方记进 `docs/releases/2026-10-试用摩擦记录.md`。
