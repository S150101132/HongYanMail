# 2026-10-21 · 统一命令入口 Ctrl+K（A2）

依据：[AI 优先的交互 · 整体计划](../superpowers/specs/2026-10-21-ai-first-interaction-plan.md) A2。

## 功能

- **Ctrl+K 打开命令框**（任何页面，包括写信时）；搜索框提示里也写了「命令 Ctrl+K」。↑↓ 选择，Enter 执行，Esc 或再按 Ctrl+K 关闭，点框外也关闭。
- **本机匹配，不调 AI**：输入功能名或别名，匹配整名、开头、包含、名字在输入里（"打开设置"）、按顺序出现的字（"写邮" → 写邮件）。能找到：
  - **这封邮件**：阅读窗格工具栏上当前看得见的每个按钮（回复、删除、移动到…、标为未读、星标、总结、AI 回复、查找、打印、新窗口……），直接按那个按钮，所以行为和按钮一致；另有作为附件转发、导出为 PDF、导出为 .eml、问问这封邮件（打开对话并带上这封）。
  - **已选 N 封**：多选时底部批量按钮。
  - **命令**：问邮箱、写邮件、从模板新建、收信、高级搜索、只看未读 / 星标 / 全部、会话分组、当前文件夹全部标为已读、新建文件夹、隐藏左侧栏、新建任务、解锁个人证书、设置、退出鸿雁、退出登录。
  - **外观**：深色 / 浅色 / 跟随系统、紧凑 / 舒适（立即生效并保存）。
  - **前往**：每个文件夹，以及定时发送、发件箱、本机草稿、本地存档、任务、待我处理、需要知道、通讯录。
  - **设置**：设置里的每一页（常规、写信、AI 助手、收信规则……）。
  - 列出的快捷键取自按钮提示（R、A、Delete…）。
- **用平常的话写搜索条件**：未读、星标、带附件、仅主题；今天、昨天、本周、上周、本月、上个月、今年、近 N 天 / 周 / 个月；「来自张三」「张三发的」。剩下的词作为关键字，"找一下所有关于…的邮件"这类说法会去掉。结果显示为「搜索邮件：有附件 · 上周 · 发件人：张三 · 「报价」」，执行后和高级搜索一样带条件标签，可以逐个去掉。
- **匹配不到的交给 AI**：最后一项总是「问邮箱：…」，打开 A1 的对话侧栏提问。像问题的输入（带问号、吗、什么、谁、哪、多少、有没有、总结、帮我……）把「问邮箱」排在第一；有明确命令时命令在前；其余先搜索。
- **任务中心**：在任务页时多一项「任务助手：…」，交给现有的任务命令（`runCommand`）。

## 不变

- 不调 AI 就能用；没配 AI 时选「问邮箱」会在侧栏里提示去设置。
- 命令只是现有按钮和函数的另一个入口，没有新的写操作。

## 代码

- `web/commands.js`（新）：前半是不依赖页面的 `cmdNorm`、`cmdScore`、`cmdIsQuestion`、`cmdParse`；后半是命令表（每次打开时按当前状态生成）、排序和面板，`window.CP = { open, close, rank, commands }`。
- `web/index.html`：`#palette`，最后加载 `commands.js`；`app.js`：Ctrl+K；`style.css`：`.palette`、`.cp-*`。
- `tests/test_commands.py`（新）：在 node 里跑匹配和条件解析（没有 node 时跳过），并检查接线。
- `tools/screenshot_commands.py`（新）：走查空框、按名字找、这封邮件的命令、条件解析和搜索结果、交给问邮箱，截图在 `analysis/screens-cmd`。

1. Ctrl+K 输入"深色"回车、"收件箱"回车、"设置 AI"回车，都直接生效。
