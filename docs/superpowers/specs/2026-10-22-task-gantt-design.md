# 任务关系与甘特图（P1）— 设计文档

日期：2026-10-22　状态：已实现，待真机验收（[记录](../../releases/2026-10-22-memory-m2-m3-gantt-p1.md)）
依据：路线图 P1；讨论稿 [AI Email_2026-10-19](../../roadmap/AI%20Email_2026-10-19.md)「任务 + 项目融合工作台」；用户 2026-10-22 要求完成。

## 1. 目标

- 任务之间有两种关系：**上级 / 子任务**（父子）和**前置 / 后续**（前置完成后才能开始）。
- 父任务汇总子任务进度；前置任务完成后，提示把受阻的后续任务改回「进行中」。
- 甘特图：按开始日期 / 计划完成日期画条形，显示父子层级、依赖箭头、今天和逾期。

## 2. 关键决策：关系写在「阻塞与依赖」里

| 方案 | 结论 |
| --- | --- |
| 新加 Excel 列 | 不采用：任务字段与两份工作簿的 15 列一一对应，迁移要求无损；加列会改工作簿结构和核验规则 |
| **从「阻塞与依赖」解析** | 采用：人已经在这一列写依赖，T1b 的任务助手也写「依赖 #编号」；Excel 里看得到、改得了，往返无损 |

写法（`tasks/plan.py`）：

- 前置：`依赖 #12`、`前置 #12`、`等待 #12`、`先完成 #12`；一处可以写多个：`依赖 #12、#13 和 #14`。
- 上级：`上级 #8`、`属于 #8`、`父任务 #8`（只取第一个）。
- 其他文字照旧是说明。指向不存在的编号只显示为「无效」，不参与计算；指向自己的忽略。
- 保存「阻塞与依赖」时检查成环（上级链或前置链回到自己），成环报 `TASK_RELATION_CYCLE`，不写入（`TaskCenter._write`，手动编辑、自然语言计划和 AI 计划都经过这里）。

## 3. 界面

- **任务详情**：日期行下面一块「关系」：上级、子任务（进度条 x/y 完成，已取消的不计）、前置（还有几条未完成）、后续、无效编号；点编号打开那条任务。「设置关系」对话框填上级和前置编号，鸿雁改写「阻塞与依赖」里的关系部分（其余文字保留），经「核对修改」后保存。
- **解除受阻**：标记完成（手动、命令框、对话侧栏的计划）后，后端返回 `unblocked`：状态是「受阻」、前置全部已完成的后续任务。页面提示「#N 不再受阻」，按「改为进行中」才修改，不自动改。
- **甘特图**：任务列表标题旁「甘特图」，画当前标签页和筛选下有日期的任务，父任务在上、子任务缩进；条形从开始日期到计划完成日期（已完成的到结束日期），只有一个日期的显示为一天；颜色：计划、逾期（红）、等前置（橙）、受阻（斜纹）、已完成（绿）；父任务是细条，绿色部分是子任务完成比例；箭头从前置任务的结束指向后续任务的开始；红竖线是今天，打开时滚到今天。点一行打开任务。最多画 400 天。

## 4. 不做

- 不自动排期、不自动改日期、不算关键路径。
- 不自动改状态：解除受阻只提示。
- 关系不进 Excel 新列，也不改「任务管理说明」的列定义。
